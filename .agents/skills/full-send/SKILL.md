# Full send

Read the shared [Loom runtime contract](../loom-workflows/references/runtime.md). It preserves current permissions, exact models and work ownership.

Do not trigger from enthusiasm or ordinary emphatic wording. Explicit invocation selects delivery through a checked merge of this task. Preserve the user's exact objective, workspace, model choices, ownership and repository gates. It does not authorize production rollout, new production dependencies, unrelated PRs or another owner's branch.

Finish the change, prove relevant behavior, and run the required checks. Use a requested bounded [sol-loop](../sol-loop/SKILL.md) only when review delegation is within the instruction; otherwise perform the authorized verification without inventing workers. Use [file-pr](../file-pr/SKILL.md) and [babysit-pr](../babysit-pr/SKILL.md) when the repository/request calls for a PR; do not create an unsolicited PR where prohibited.

Merge only after current-head proof, required checks/reviews and base compatibility pass. Respect branch protection and avoid admin bypasses. Resolve routine reversible work autonomously. Use structured questions for truly missing account steps or irreversible choices. Browser/device restrictions remain governed by the actual authorization and higher-priority rules. Report final head/merge, evidence, material limits and owned cleanup.
