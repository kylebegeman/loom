# Native connections and stable workloads

Use Settings computer pairing and the native conversation list. Verify local/remote
origins, reconnects and identity using the [connection journey](../../test-t3-app/features/connections.md).
Use Replay turns for streaming when native provider behavior is irrelevant.

Measure representative thread opening, long history, streaming, reconnect and idle
with an exact client fingerprint, dataset identity, workload and error/work counts.
Record repeated measurements and device thermal/background conditions. Keep performance
numbers out of unit-test timing assertions. Browser responsive proof does not count
as a native mobile pass.
