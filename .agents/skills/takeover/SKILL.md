# Takeover

Read the shared [Loom runtime contract](../loom-workflows/references/runtime.md). It preserves current permissions, exact models and work ownership.

Read the source conversation or PR, including later corrections and the current working tree. Resolve its state to actual commits and files. Treat the handoff as context, then independently verify claims and preserve the user's original objective.

Use [modernize](../modernize/SKILL.md) to reconcile current architecture. Preserve authorship and co-author trailers with verified identities. Honor an in-place continuation or existing bound worktree; do not create another checkout or replace another owner's work by default.

Finish the authorized goal and focused verification. Fix inherited defects within that goal rather than defending the old implementation. Use [file-pr](../file-pr/SKILL.md) and [babysit-pr](../babysit-pr/SKILL.md) only when requested delivery includes them. Report inherited work, actual changes, evidence, limitations, final branch/head and cleanup ownership.
