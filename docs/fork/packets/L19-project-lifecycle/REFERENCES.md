# L19 references

## Kyle's workspace

- `~/Developer/docs/workflow/ephemeral-checkouts.md`: the lifecycle (start, work, finish,
  park) and what "nothing unique" means: zero dirty files, zero commits not on the remote,
  zero stashes, ignored files classified (build output is fine to lose; local databases,
  `.env` files and recordings are not). Lessons: 53 GB Rust `target/` folders must never
  argue for keeping a checkout; a local-only `backup/pre-replay` branch is why every branch
  gets pushed.
- `~/Developer/docs/llm/START_HERE.md`: `~/Developer/active/<name>` holds checkouts, nested
  one level for multi-repo products; a checkout can disappear once pushed.
- `~/.local/bin/dev-park`: the CLI stopgap this packet mirrors. Checks in order: `.git`
  exists, `origin` exists, clean `git status --porcelain` (or `--wip` commit), no stashes,
  `git fetch origin`, push every local branch (`git push -u origin <b>`) and tags,
  `git log --branches --not --remotes` empty, then `mv` into
  `~/.Trash/<name>-<yyyymmdd-hhmmss>`. Keep: all of it. Add: ignored-file classification,
  linked worktrees, nested repositories, running threads, a stale-report guard.

## External

- macOS `/usr/bin/trash` (ships with macOS 15 and later; verified present on this Mac,
  macOS 27): `trash [-v] [-s] file...`, moves items to the Trash with Finder semantics.
  Behavior on older macOS is unverified; the fallback rename covers it.
- GLib `gio trash`: freedesktop.org Trash specification implementation on Linux
  (https://docs.gtk.org/gio/ and `man gio`).
- GitHub REST `GET /user/repos` with `affiliation`
  (https://docs.github.com/en/rest/repos/repos#list-repositories-for-the-authenticated-user).
- `gh api --paginate --slurp` (https://cli.github.com/manual/gh_api).
- Git: `git status --porcelain=v1 -z --ignored=matching`, `git worktree list --porcelain`,
  `git for-each-ref` (https://git-scm.com/docs).
