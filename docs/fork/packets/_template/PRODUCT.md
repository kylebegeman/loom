# Lxx product

What the feature is for. Written by or with Kyle before any technical design.

## Problem

The user need in two or three sentences. Who hits it and when.

## What the user can do

The behaviors, as short user-facing statements ("Open the Snippets panel from the launcher
or with a shortcut").

## Entry points

Every way in: right panel launcher, command palette, keybinding, settings, composer, context
menu, mobile screen. Every way out and every way to see the state (AGENTS.md, "Reverse
states").

## States

Loading, empty, error, disabled (server lacks the feature), and any in-progress state.

## Surfaces and connection modes

Which surfaces are supported and what the others show. Behavior on a remote environment and
on an upstream T3 server.

## Decisions and open questions

Choices already made, with a one-line reason each, and questions Kyle still has to answer.
Packets marked "design session first" record that session's outcome here.
