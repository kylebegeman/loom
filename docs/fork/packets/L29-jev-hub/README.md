# L29: Jev hub

Status: Retired. Kyle approved retiring the whole packet on 2026-10-09: Jev moved to its own
project outside Loom, and Loom drops all Jev support, including the shared `ext-decide`
extension point and the optional Jev decisions in other packets. Nothing was built.

The packet proposed a Decisions panel, a playground, question templates, ratings and replay
for those decisions. Its design documents were removed from this folder; git history keeps
them (for example `git show 80f06b1025:docs/fork/packets/L29-jev-hub/PRODUCT.md`). Do not
implement it in Loom.
