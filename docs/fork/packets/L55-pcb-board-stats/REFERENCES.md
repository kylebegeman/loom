## Prior art

- KiCad's Inspect, Board Statistics dialog: footprint counts per side, pad and via counts, drill
  table, board area. The card mirrors its scope minus the drill table.
- Fab quote forms (JLCPCB, PCBWay, OSH Park) ask for size, layers, thickness, smallest
  track and space, smallest hole and annular ring; those set the list. Not re-fetched.
