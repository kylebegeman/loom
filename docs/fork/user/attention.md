# Threads that need you

Choose **N need you** in the thread list to see approvals, questions, paused queues and failed runs. Open an approval or question to answer it in its thread. **Resume queue** releases paused work. Bot runs appear in their own **Bots: N waiting** entry, which opens the Bots inbox.

After a temporary provider failure, **Retry** continues the failed run with the thread's current settings. **Retry all retryable** tries the listed runs one at a time and shows each result. A changed run or pending question stops that retry safely; other retries continue. Permission and validation failures need a changed message instead.

**Retry failed run** is also in the thread menu and command palette. Its shortcut is unbound until you assign one in Keybindings. The existing next-attention shortcut still jumps between threads. These controls work on web, desktop and mobile when the connected computer supports them.
